Family Cast Photos — Auto-Load Folder
=====================================

The dashboard (Orlando_Family_Dashboard.html) will look for photos
in this folder and load them automatically as default avatars.

HOW TO USE:
-----------
Save each family member's photo here using the exact filename below.
Square photos work best (cropped face/headshot, 300-500px).
Supported: .jpg, .jpeg, .png, .webp

FILENAMES (use lowercase exactly as shown):

  abuitemo.jpg     →  Abui Temo  (Mickey Mouse)
  abui.jpg         →  Abui       (Minnie Mouse)
  art.jpg          →  Art        (Luigi)
  annelise.jpg     →  Annelise   (Mario)
  sandra.jpg       →  Sandra     (Princess Peach)
  martha.jpg       →  Martha     (Daisy)
  danny.jpg        →  Danny      (Donkey Kong)
  valeria.jpg      →  Valeria    (Goofy)
  isabella.jpg     →  Isabella   (Belle)
  victoria.jpg     →  Victoria   (Anna)
  valentina.jpg    →  Valentina  (Winnie the Pooh)
  john.jpg         →  John       (Darth Vader)
  anette.jpg       →  Anette     (Mirabel)

NOTES:
------
- The dashboard checks this folder every time it loads.
- If a photo is uploaded via the dashboard's click-to-upload feature,
  THAT photo wins — it's saved to your browser and overrides the file here.
- To go back to the file-based default, use the dashboard's ✕ button to
  clear the browser-saved photo.
- These photos stay 100% local. They never upload anywhere.

QUICK CROP TIP:
---------------
On Windows: open photo in Photos app → Edit → Crop to Square → Save As.
On phone: most galleries have a built-in crop tool.
